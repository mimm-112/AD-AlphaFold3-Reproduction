# BlindSpot

**AlphaFold3 · Boltz-2 기반 미스센스 변이 구조 예측 감별력 검정 플랫폼**
*Mutation Detectability Assessment Platform for AlphaFold3 · Boltz-2*

동일 서열을 반복 예측해 모델 고유의 **재현 변동성**을 음성 대조군으로 확보하고,
야생형–변이형 간 구조 및 결합 인터페이스 편차가 이를 초과하는지 비모수 검정으로 판정하여,
해당 예측을 근거로 사용할 수 있는지 사전에 선별하는 시스템

**근거 데이터** Yao et al. (2024) *Cell Genomics* 4:100700 재현 실측
**저장소** https://github.com/mimm-112/AD-AlphaFold3-Reproduction
**데모**   https://mimm-112.github.io/AD-AlphaFold3-Reproduction/app/  ← 실제 동작

# 1. 서비스 정의

## 1.1 한 문장

> **"이 변이에 대해 구조 예측을 증거로 쓸 수 있는가"** 를 판정한다.

## 1.2 정의

동일 조건 반복 예측으로 **모델 재현 변동성(intra-condition variability)** 을 음성 대조군으로 확보하고,
**야생형–변이형 간 구조적 편차**가 이를 초과하는지 비모수 검정으로 판정하여,
해당 예측의 **증거 사용 적합성**을 보고한다.

## 1.3 성격

**발견(discovery) 도구가 아니라 선별(triage) 도구다.**
변이의 생물학적 효과를 규명하지 않으며, 구조 예측이라는 방법론이 해당 변이에 적용 가능한지를 판정한다.

# 2. 존재 근거

## 2.1 문제의 실재 — 실측 근거

동료심사를 거쳐 게재된 논문이 본문 Figure 4B에 **CD33 R69G의 구조적 변화**를 대표 사례로 제시했다.
동일 조건 재현 결과:

| 항목 | 값 |
|---|---|
| 동일 조건 반복 예측 편차 (n = 20) | 0.124 Å [0.045–0.186] |
| 야생형–변이형 간 편차 (n = 25) | 0.120 Å |
| Δ | −0.004 Å |
| Mann–Whitney U, 단측 | **p = 0.54** |

**귀무가설 기각 실패.** 게재 논문의 대표 도해가 검정을 통과하지 못한다.

## 2.2 원인 — 모델의 구조적 특성

| 원인 | 근거 |
|---|---|
| AlphaFold는 구조 붕괴 변이 데이터베이스로 학습되지 않아 야생형·상동 서열 기반으로 예측 | Buel & Walters (2022) *Nat Struct Mol Biol* |
| Boltz-2 affinity는 결합부위 변이에 둔감하며, 타겟 교체에도 분류가 유지되는 사례 존재 | Bret et al. (2026) *J Chem Inf Model* |
| 확산 기반 생성 모델의 비결정적 출력 — 동일 입력에 상이한 구조 | 모델 아키텍처 |

개별 사용자의 오류가 아니라 방법론의 구조적 한계다.

## 2.3 ★ 기존 신뢰도 지표는 변이 감별력을 보장하지 않는다

본 서비스의 핵심 논거. 현행 지표(pLDDT · pTM · ipTM)는 **예측 구조의 정확도**를 추정할 뿐이며,
**변이 반영 여부**와는 다른 값을 측정한다. 본 연구 실측이 이를 직접 보인다.

| 사례 | 모델 보고 신뢰도 | 변이 감별 |
|---|---|---|
| **CD33 R69G** | 도메인 pLDDT **97.3** · 변이부위 pLDDT **96.7–97.1** · pTM 0.59–0.60 | **미검출** (p = 0.54) |
| **TREM2 R62H + Aβ42** | ipTM **0.851** (통상 ≥0.8 신뢰) · complex pLDDT 0.856 | **미검출** (p = 0.30) |

고신뢰 조건에서도 변이 효과가 검출되지 않는다.
**pLDDT 97은 해당 위치 구조에 대한 확신을 의미할 뿐, 변이 반영을 의미하지 않는다.**

## 2.4 공백 — 현행 도구는 이 값을 제공하지 않는다

| 도구 | 제공 지표 | 변이 감별력 보고 |
|---|---|---|
| AlphaFold Server (AF3) | 구조, pLDDT, pTM | ✕ |
| Boltz-2 | 복합체, ipTM, affinity | ✕ |
| AlphaMissense | 병원성 점수 | ✕ (구조 편차 미산출) |
| FoldX · Rosetta | ΔΔG | ✕ (예측 모델 변동성 미반영) |

## 2.5 미검정 사용의 비용

구조적 편차는 **기전 서술의 근거**로 사용된다 — 논문, 특허 명세, 과제 제안서, 타겟 우선순위 결정.
근거가 모델 재현 변동성이었을 경우 후속 실험 자원이 소모된다.

## 2.6 시의성

AF3 웹서버 및 Boltz-2(MIT) 공개로 변이 구조 예측의 진입장벽이 제거되었다.
사용량 증가에 비례하여 미검정 사용도 증가한다.

# 3. 서비스 범위

## 3.1 답하는 것

| 질문 | 출력 |
|---|---|
| 이 예측을 구조적 변화의 근거로 사용할 수 있는가 | **변이 효과 검출 / 미검출** + p + 효과크기 |
| 모델이 이 변이를 감별할 수 있는가 | 재현 변동성 대비 편차 비율 |
| 계산을 더 진행할 것인가, 실험으로 이행할 것인가 | 판정에 따른 분기 |
| 다수 변이 중 구조 예측이 유효한 것은 어느 것인가 | **증거 사용 가능성 기준 정렬** |

## 3.2 ⚠️ 답하지 않는 것 — 명시적 경계

| 질문 | 제공 |
|---|---|
| 이 변이가 병원성인가 | ✕ |
| 이 변이가 단백질 기능을 변화시키는가 | ✕ |
| 변이가 무엇을 손상시키는가 (접힘·결합면·안정성·활성부위) | ✕ |
| 약물 결합 부위가 변화했는가 (druggability) | ✕ |
| 실제로 구조가 불변인가 | ✕ — **미검출 ≠ 무변화** |

## 3.3 미검출 판정의 해석 — 세 가능성

미검출은 다음 세 경우를 구분하지 못한다. 이는 본 서비스의 명시적 한계다.

| | 내용 |
|---|---|
| (a) | 접힘이 실제로 변화하지 않음 — 모델이 정확히 산출 |
| (b) | 접힘이 변화하나 모델이 포착하지 못함 — 모델 한계 |
| (c) | 변이 효과가 접힘이 아닌 다른 층위 — 결합·발현·수송·안정성·PTM |

**따라서 판정 문구는 "구조 변화 없음"이 아니라 "본 예측으로 판단 불가"로 산출한다.**

## 3.4 정렬 결과의 의미 — 오독 방지

산출되는 순위는 **증거 사용 가능성 순위이며 생물학적 중요도 순위가 아니다.**

| 사례 | 재현 변동성 | 변이 편차 | 비율 |
|---|---|---|---|
| PILRA R78G | 0.100 Å | 0.995 Å | **10.0×** |
| TREM2 R62H | 0.168 Å | 0.257 Å | 1.5× |
| CD33 R69G | 0.124 Å | 0.120 Å | 0.97× |

CD33 R69G는 원논문이 AD 위험 증가로 지목한 변이이나 본 지표에서 최하위다.
**모델이 감별하지 못하는 것이며 생물학적 중요도가 낮음을 의미하지 않는다.**

## 6.1 [화면 : HOME]

**요약 설명**

1. **서비스 정의 헤더** — "구조 예측 모델의 변이 감별력 사전 검정 플랫폼"
2. **문제 제시 패널** — 동일 서열 반복 예측 구조 2개를 병치하여 재현 변동성의 존재를 즉시 제시
3. **검정 원리 도식** — 음성 대조군 구성 → 처리군 대비 → 비모수 검정
4. **근거 문헌 카드** — Buel & Walters 2022 · Bret et al. 2026 (모델 한계) / Yao et al. 2024 (재현 대상), DOI 링크
5. **핵심 논거 표** — pLDDT 97 · ipTM 0.85 조건에서의 미검출 사례 (2.3절 표)
6. **사례 진입** — `CD33 R69G` · `PILRA R78G` · `TREM2 R62H` · `TREM2+Aβ42`
7. **서비스 경계 고지** — "본 서비스는 변이의 생물학적 효과를 규명하지 않으며 예측의 증거 사용 적합성만 판정한다" (상시 노출)
8. **저장소 링크** — 코드 10종 · 예측 구조 60개 전량 공개

## 6.2 [화면 : 변이 입력 및 검증]

**요약 설명**

1. **UniProt accession 입력** — 조회 후 단백질명 · 길이 · 도메인 경계 · 신호펩타이드 구간 표시
2. **변이 표기 입력** — 전구체(precursor) 번호 기준임을 명시. 형식 `[야생형][위치][변이형]`
3. **잔기 대조 검증** — 해당 위치의 정본 잔기를 조회하여 입력값과 대조
   · 일치 → 진행 활성화
   · **불일치 → 실제 잔기 표시 후 진행 차단** (예: PILRA 78번 입력 시 "정본 서열의 78번은 Arg")
4. **예측 구간 선택** — 전장 / 도메인 절단. 도메인 선택 시 UniProt 주석 경계를 기본값으로 제안
5. **앙상블 파라미터** — 샘플 수 n (기본 5) · 시드 (기본 1, 기록됨)
6. **서열 대조 뷰** — 야생형·변이형 병치, 상이 잔기 1개만 강조 표시
7. **입력 파일 배포** — AlphaFold Server 업로드용 JSON · Boltz-2 YAML 동시 생성

> **설계 근거** 3번 검증은 본 연구에서 PILRA 변이 방향 오류(문헌 표기 `G78R` vs 정본 `R78G`)를 사전 차단한 로직이다.

## 6.3 [화면 : 구조 축 감별력 검정]

**요약 설명**

1. **3D 오버레이 (Mol\*)** — 야생형 / 변이형 병치, 변이 잔기 stick 표시
2. **`재현 앙상블 표시` 토글** ★ 핵심 기능
   · 활성화 시 **동일 서열로 산출된 구조 n개를 동시 표시**
   · 재현 변동성의 크기를 시각적으로 제시
3. **변이 부위 확대** — 해당 잔기로 시점 이동, 8 Å 반경 강조
4. **분포 도표** — 음성 대조군 / 처리군 편차 분포를 동일 축에 표시, 중앙값 표기
5. **판정 카드** (7절 사양)
6. **측정 조건 패널** — 정렬 구간 · 컷오프 · 검정 방식 · 시드 · 샘플 수
7. **원자료 배포** — 구조 파일 · 편차 쌍 CSV

## 6.4 [화면 : 결합 축 감별력 검정]

**요약 설명**

1. **결합 상대 입력** — 펩타이드 서열 또는 리간드 SMILES (사례 기본값: Aβ42, APP 672–713)
2. **복합체 3D 뷰어 (Mol\*)** — 사슬별 색 구분, 인터페이스 잔기 강조
3. **ipTM 분포 도표** — 야생형 / 변이형, 구조 축과 동일 형식
4. **판정 카드** — ipTM 중앙값 · 범위 · Δ · p · 검출 여부
5. **지표 정의 고지** ⚠️
   · ipTM은 결합 자유에너지가 아닌 **인터페이스 예측 신뢰도 지표**
   · Boltz-2 affinity head는 **small-molecule 전용**이며 펩타이드에 미적용
6. **관련 실험 문헌** — 해당 단백질에 대해 보고된 결합 실험 (TREM2: Zhao 2018 · Zhong 2018 · Yeh 2016)
7. **해석 비제공 고지** — 결합 변화 여부에 대한 판단은 제공하지 않음

## 7.1 변이 효과 미검출 — 구조 축

```
CD33 · R69G  (rs2455069)
판정: 변이 효과 미검출 — 모델 감별력 미달

    동일 조건 반복 예측 편차     0.124 Å   [0.045–0.186]   n = 20
    야생형–변이형 간 편차        0.120 Å                    n = 25

     변이에 기인한 구조 편차가 모델 재현 변동성과

  ※ 구조 불변을 의미하지 않으며 본 모델의 감별 한계를 의미함.
```

```
TREM2 · R62H  (rs143332484)
판정: 변이 효과 검출 — 효과크기 미미
```
