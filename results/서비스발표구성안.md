**내레이션**

지금부터는 앞의 재현 결과를 도구로 만든 부분을 말씀드리겠습니다.

서비스 이름은 BlindSpot입니다. 구조 예측 모델에는 사각지대가 있습니다. 어떤 변이는 모델이 아예 보지 못하는데, 지금은 그걸 확인할 방법이 없습니다. 이 도구는 그 사각지대를 먼저 찾아 줍니다.

방식은 간단합니다. 같은 서열을 여러 번 예측하면 모델은 매번 조금씩 다른 구조를 내놓습니다. 그 흔들림의 크기가 곧 기준선입니다. 변이를 넣어 생긴 차이가 그 기준선을 넘는지 통계적으로 판정합니다.

**소요 시간** 40초

## Slide 02 · 서비스 존재 근거 `svc_02_존재근거.png`

**화면**

**문제**
· 구조 예측 모델은 확률적 생성 모델이므로 동일 서열에도 **비결정적 출력**을 낸다
· 따라서 관측된 편차가 변이 때문인지 모델 변동 때문인지 구분되지 않는다

**실측 근거**
· 게재 논문이 본문 Figure 4B에 CD33 R69G의 구조 변화를 대표 사례로 제시
· 동일 조건 재현 결과 **p = 0.54** — 귀무가설 기각 실패

**고신뢰 조건에서도 변이가 검출되지 않는다**

| 사례 | 모델 보고 신뢰도 | 변이 감별 |
|---|---|---|
| CD33 R69G | 도메인 pLDDT 97.3 · pTM 0.60 | 변동성 내 · p 0.54 |
| TREM2 R62H + Aβ42 | ipTM 0.851 · complex pLDDT 0.856 | 변동성 내 · p 0.30 |

**선행 연구**
· Buel & Walters (2022) *Nat Struct Mol Biol* — AF2는 구조 붕괴 변이 DB로 학습되지 않음
· Bret et al. (2026) *JCIM* — Boltz-2 affinity의 결합부위 변이 둔감성
· 두 문헌 모두 **한계를 지적했을 뿐 정량 기준은 제시하지 않았다**

**내레이션**

왜 이런 도구가 필요한지부터 말씀드리겠습니다.

구조 예측 모델은 확률적으로 구조를 생성합니다. 같은 서열을 넣어도 매번 결과가 다릅니다. 그래서 야생형과 변이형을 겹쳐 보고 차이를 발견해도, 그게 변이 때문인지 모델이 원래 흔들리는 건지 알 수 없습니다.

이건 추정이 아닙니다. 앞에서 보신 것처럼, 동료심사를 거쳐 게재된 논문이 본문 대표 그림으로 실은 CD33 사례가 재현 결과 p값 0.54로 기준선을 넘지 못했습니다.

**여기서 중요한 지점이 하나 있습니다.** 오른쪽 표를 보시면, 두 사례 모두 모델이 보고한 신뢰도는 최상급입니다. pLDDT 97, ipTM 0.85입니다. 그런데도 변이는 검출되지 않았습니다. **pLDDT 97은 그 위치의 구조를 확신한다는 뜻이지, 변이를 반영했다는 뜻이 아닙니다.** 이 둘이 현장에서는 구분 없이 쓰입니다.

관련 한계는 이미 문헌에 보고되어 있습니다. AlphaFold2가 미스센스 변이에 둔감하다는 지적도, Boltz-2가 결합부위 변이에 둔감하다는 보고도 있습니다. 다만 두 문헌 모두 지적에 그쳤고 정량 기준은 없습니다. 그리고 현행 도구 중 변이 감별력을 별도로 보고하는 것은 하나도 없습니다.

**소요 시간** 1분 30초

**⚠️ 발표 프레이밍**
"논문이 틀렸다"가 아니라 **"현행 도구에 빠진 기능이 있다"** 로 전달한다.
CD33 사례는 문제의 실재를 보이는 근거로만 쓰고, 논문 비판으로 확대하지 않는다.

## Slide 03 · 서비스 파이프라인 `svc_03_파이프라인.png`

**화면**

**6단계 흐름**

| | 단계 | 기술 |
|---|---|---|
| 1 | 서열 확보 · 변이 검증 | UniProt REST |
| 2 | 구조 앙상블 생성 *(사용자 수행)* | AlphaFold Server · Boltz-2 |
| 3 | 음성 대조군 구성 | Horn 중첩 |
| 4 | 감별력 검정 | Mann–Whitney U |
| 5 | 결합 인터페이스 확장 | Boltz-2 · ipTM |
| 6 | 판정 리포트 | Mol* · SVG |

**검정 설계**

| 항목 | 내용 |
|---|---|
| H₀ | 야생형–변이형 편차 = 동일 조건 반복 예측의 변동 |
| H₁ | 변이형 편차가 재현 변동성을 초과한다 |
| **음성 대조군** | **동일 서열의 모델 쌍** — 변이가 없으므로 관측 편차는 전부 모델 변동 |
| 검정 | Mann–Whitney U · α = 0.05 |
| 통제 변수 | 동일 도구 · 동일 구간 · 시드 고정 · 동일 샘플 수 |

**구현 현황** — 5개 실동작 / 1개 미구현(구조 예측 실행, GPU 필요)

**내레이션**

파이프라인은 6단계입니다.

첫째로 UniProt에서 서열을 가져와 변이를 검증하고, 둘째로 구조를 여러 번 예측합니다. 셋째로 같은 서열끼리의 쌍을 음성 대조군으로 묶고, 넷째로 야생형과 변이형 쌍을 그 대조군과 비교해 검정합니다. 다섯째로 복합체가 있으면 같은 절차를 결합 인터페이스에도 적용하고, 여섯째로 판정을 리포트로 냅니다.

핵심은 세 번째 단계입니다. **음성 대조군에는 변이가 없습니다.** 그러므로 거기서 관측되는 편차는 전부 모델 자체의 변동입니다. 이것이 "구조가 변했다"를 판정할 기준선이 됩니다. 논문에는 이 기준선이 없었습니다.

여섯 단계 중 다섯 개는 브라우저에서 실제로 동작합니다. 두 번째 단계인 구조 예측만 GPU가 필요해서 사용자가 AlphaFold Server에서 직접 수행합니다. 무료이고, 하루 30건까지 가능합니다.

**소요 시간** 1분 20초

## Slide 05 · 화면 · 분석 `svc_05_화면_분석.png`

**화면** 분석 화면 스크린샷 + 콜아웃 7개

**내레이션**

분석 화면입니다. **이 화면은 임의의 단백질에 대해 실제로 동작합니다.**

UniProt accession을 입력하면 REST API를 직접 호출해 단백질명과 길이, 신호펩타이드와 도메인 경계를 가져옵니다. 변이 표기를 넣으면 해당 위치의 실제 잔기와 대조합니다.

**여기가 이 도구의 첫 번째 실질 기능입니다.** 예를 들어 PILRA 변이를 문헌 표기대로 G78R로 입력하면 진행이 차단됩니다. UniProt 정본 서열의 78번은 이미 아르기닌이기 때문입니다. 그러면서 올바른 표기인 R78G를 제시합니다. 앞의 재현 과정에서 실제로 이 오류를 사전에 막았던 검증 로직을 그대로 이식한 것입니다.

검증을 통과하면 야생형과 변이형 서열을 나란히 보여주고 다른 글자 하나만 강조합니다. 그리고 AlphaFold Server용 JSON, Boltz-2용 YAML, FASTA를 내려받을 수 있습니다.

아래쪽이 이번에 추가한 부분입니다. 파일을 내려받아 AlphaFold Server에서 예측한 뒤, **결과 ZIP을 여기에 올리면 브라우저가 구조를 직접 읽어 편차를 계산하고 검정합니다.** 파일은 서버로 전송되지 않습니다.

**소요 시간** 1분 20초

**시연 포인트** 여기서 라이브 시연을 하면 가장 효과적이다. 아래 "시연 시나리오" 참조.

## Slide 07 · 화면 · 결합 인터페이스 검증 `svc_07_화면_결합인터페이스.png`

**화면** 결합 검증 화면 스크린샷 + 콜아웃 5개

**내레이션**

구조에서 답이 나오지 않으면 결합을 봅니다. 실험 문헌은 TREM2 R62H가 아밀로이드 베타 결합을 떨어뜨린다고 보고합니다. 그래서 Boltz-2로 TREM2와 아밀로이드 베타 42의 복합체를 예측하고, 구조 검증과 똑같은 절차를 적용했습니다.

결과는 p값 0.30입니다. 야생형 0.851, 변이형 0.824인데 같은 조건에서도 0.56에서 0.90까지 흔들립니다. 차이가 흔들림에 완전히 묻혔습니다.

**정확하게 말씀드릴 것이 하나 있습니다.** 여기서 쓰는 ipTM은 결합 자유에너지가 아니라 인터페이스 예측 신뢰도 지표입니다. Boltz-2의 결합 친화도 기능은 저분자 전용이라 펩타이드인 아밀로이드 베타에는 적용되지 않습니다. **따라서 이 화면은 결합력 수치를 산출하지 않습니다.** 화면에도 그렇게 표기했습니다.

**소요 시간** 1분

## Slide 08 · 화면 · 리포트 / 방법론 `svc_08_화면_리포트방법론.png`

**화면** 리포트 화면 스크린샷 + 콜아웃 3개 + 방법론 화면 설명

**내레이션**

마지막으로 리포트입니다. 전 사례의 기준 변동, 측정 편차, 비율, p값, 판정을 한 표로 정리합니다. 모든 통계량은 하드코딩이 아니라 원자료에서 브라우저가 다시 계산한 값입니다.

문헌 대조 항목이 있습니다. Zhao 등의 2018년 보고는 이 변이가 결합을 감소시킨다고 하는데 본 모델은 감별하지 못했습니다. 그럴 때 **"문헌은 효과를 보고하나 본 모델은 미검출"** 로 표기하고, 계산이 아닌 실험적 접근이 필요한 사례로 분류합니다.

방법론 화면에는 가설과 대조군 설계, 존재 근거, 서비스 범위, 한계를 담았습니다.

정리하면, 이 도구가 답하는 질문은 하나입니다. **"이 변이에 대해 구조 예측을 증거로 쓸 수 있는가."** 변이가 무엇을 하는지는 답하지 않습니다. 그 이상을 주장하지 않는 것이 이 도구의 설계 원칙입니다.

**소요 시간** 1분

## Slide 09 · 활용 기술 스택 `svc_09_기술스택.png`

**화면**

**계층 구조** 데이터 → 예측 → **계산(자체 구현)** → 표현 → 배포
**구성 요소 및 라이선스** 외부 2 · 라이브러리 2 · **자체 구현 4**
**재현 파이프라인(연구 측)** Python 3 · PyMOL 3.1.0 · 스크립트 10종

**내레이션**

마지막으로 기술 구성입니다.

데이터는 UniProt REST API와 RCSB PDB에서 실시간으로 가져옵니다. 예측은 AlphaFold Server와 Boltz-2를 씁니다.

**가운데 계산 계층이 이 서비스의 핵심입니다.** 여기는 외부 라이브러리를 쓰지 않고 전부 직접 구현했습니다. mmCIF 파서, Horn 사원수법 최적 중첩과 Jacobi 고유분해, 국소 RMSD, 그리고 Mann–Whitney U 검정입니다. 검정은 정규근사에 연속성 보정과 동순위 보정까지 넣었습니다.

표현 계층에서 3D는 Mol*을 쓰지만 분포 도표는 SVG로 직접 그립니다. 차트 라이브러리를 쓰지 않았습니다.

배포는 GitHub Pages 정적 호스팅입니다. **빌드 과정도 서버도 없습니다.** 업로드한 파일은 클라이언트에서만 처리되고 외부로 전송되지 않습니다.

오른쪽 아래를 보시면, AlphaFold Server는 비영리 한정 라이선스입니다. 그래서 상업 전개를 고려해 예측 단계를 모델 교체가 가능한 구조로 설계했습니다. MIT 라이선스인 Boltz-2 단독으로도 동작합니다.

# 시연 시나리오 (선택 · 2분)

Slide 05 에서 진행한다. 라이브 URL 을 미리 띄워 둔다.

| | 동작 | 보여줄 것 |
|---|---|---|
| 1 | `Q9UKJ1` + `G78R` 입력 | **진행 차단** — "78번은 이미 Arg, R78G 인지 확인" |
| 2 | `R78G` 로 수정 | 통과 · 서열 생성 · dbSNP 자동 매칭 |
| 3 | 구조 검증 탭 → `CD33` | 두 분포가 겹침 · p 0.53 |
| 4 | `PILRA` 로 전환 | 확연히 분리됨 · p 6×10⁻⁹ |

**임의 단백질 요청이 나올 경우** — `P04637`(p53) `R175H`, `P42212`(GFP, 해파리) `S65T` 가 통과 사례.
`P01308`(인슐린) `H24R` 은 차단되는데, 전구체 번호 기준으로 24번이 Ala 이기 때문이다. 이것도 좋은 예시다.

**딥링크**
```
?s=s2&acc=Q9UKJ1&mut=G78R     차단 사례
?s=s2&acc=P04637&mut=R175H    p53 통과
?s=s3                          구조 검증 결과
```

# 예상 질문

**Q. 예측을 직접 돌려주지 않는 이유는?**
> GPU 가 필요하고 예측 1건에 10–30분이 걸립니다. AlphaFold Server 가 무료로 하루 30건을 제공하므로,
> 그 단계는 사용자가 수행하고 결과를 업로드하면 나머지를 처리하는 구조로 설계했습니다.

**Q. 수록 사례 외의 단백질도 되나요?**
> 검증·서열 생성·파일 배포·업로드 분석은 임의 accession 에 대해 동작합니다.
> 사전 산출 결과가 없는 입력에는 다른 사례의 결과를 표시하지 않고 안내 메시지를 냅니다.

**Q. "재현 변동성 내"는 구조가 안 변한다는 뜻인가요?**
> 아닙니다. 세 가지가 구분되지 않습니다 — 실제로 안 변했거나, 변했는데 모델이 못 봤거나,
> 효과가 접힘이 아닌 다른 층위에 있거나. 그래서 판정 문구를 "본 예측으로 판단 불가"로 냅니다.

**Q. 정렬 구간은 어떻게 정하나요?**
> 수록 사례는 알려진 도메인 경계를, 업로드 경로는 **양쪽 모두 pLDDT ≥ 70 인 잔기**를 씁니다.
> 임의 단백질에는 도메인 주석이 없을 수 있기 때문입니다.
> CD33 로 두 방식을 대조했을 때 절대값은 달랐으나 판정은 일치했습니다.

**Q. 통계가 미리 계산된 값 아닌가요?**
> 아닙니다. 원자료 CSV 를 브라우저가 읽어 Mann–Whitney U 를 직접 계산합니다.
> 그래서 SciPy 결과와 소수 셋째 자리에서 차이가 납니다 — CD33 의 경우 브라우저 0.53, SciPy 0.54 입니다.
> 하드코딩이었다면 같은 값이 나왔을 것입니다.

**Q. 상업화가 가능한가요?**
> AlphaFold Server 약관은 비영리 한정입니다. 상업 전개 시에는 MIT 라이선스인 Boltz-2 단독 구성으로
> 전환해야 하며, 그래서 예측 단계를 모델 교체가 가능한 구조로 설계했습니다.
