# 발표 전 용어 정리 · 예상 질문

*슬라이드에 나오는 단어를 전문용어 없이 풀어 쓴 것. 우리 실제 숫자와 함께.*

---

## PART 1 · 반드시 알아야 할 10개

이건 발표 중에 반드시 나옵니다. 이것만 알면 90%는 막습니다.

---

### 1. Å (옹스트롬) — 길이 단위

원자 크기를 재는 단위입니다.

```
탄소 원자 하나  ≈ 1.5 Å
단백질 도메인    ≈ 30~40 Å
```

**우리 숫자**: CD33 0.12 Å = **원자 하나 크기의 1/12**. 사실상 안 움직인 것.

---

### 2. RMSD — 두 구조가 얼마나 다른가

두 구조를 겹쳐놓고 **평균적으로 얼마나 어긋나는지** 잰 값. 단위는 Å.
0에 가까울수록 똑같음.

**우리 숫자**

| | RMSD | 뜻 |
|---|---|---|
| CD33 | 0.12 Å | 거의 안 변함 |
| TREM2 | 0.26 Å | 아주 조금 변함 |
| PILRA | 1.0 Å | 원자 하나만큼 이동, 눈에 띔 |

> 참고: 구조생물학에서 **2 Å 이하면 "같은 구조"** 로 봅니다. 우리 값은 전부 그보다 훨씬 작습니다.

---

### 3. pTM — 모델이 스스로 매긴 점수 (0~1)

AlphaFold가 "내가 예측한 이 구조, 진짜와 얼마나 비슷할까?"를 **스스로 추정한 점수**입니다.
높을수록 자신 있다는 뜻. 보통 0.8 이상이면 신뢰, 0.5 근처면 애매.

**우리 숫자**: CD33 **0.59~0.60** ← 논문이 보고한 **0.6**과 일치. 이게 "재현 성공"의 핵심 근거.

**주의**: 0.6은 높은 점수가 아닙니다. 논문은 "good prediction"이라 했지만 그건 관대한 표현.

---

### 4. pLDDT — 부위별 확신도 (0~100)

pTM이 "전체 점수"라면, pLDDT는 **아미노산 하나하나가 얼마나 확실한지**입니다.

```
90 이상  매우 확실
70~90   믿을 만함
50 이하  흐물흐물, 못 믿음
```

**우리 숫자** — 이게 발표의 중요한 반전입니다.

| 단백질 | 전체 평균 | **Ig 도메인만** |
|---|---|---|
| CD33 | 71 | **97** |
| PILRA | 64 | **97** |
| TREM2 | 66 | **94** |

→ **pTM 0.6이 낮은 건 단백질이 못 접혀서가 아니라, 꼬리가 흐물흐물해서입니다.**
   변이가 있는 핵심 부위는 pLDDT 94~97로 최상급입니다.

---

### 5. 미스센스 변이 (missense variant)

DNA 한 글자가 바뀌어서 **아미노산이 다른 것으로 바뀌는** 변이.

```
CD33: DNA의 A → G  →  69번 아미노산이 아르기닌 → 글리신
```

**중요**: 7개 단백질 중 이런 변이가 있는 건 **3개뿐**입니다.
나머지 4개는 변이가 있어도 아미노산이 안 바뀌어서 **구조 그림을 만들 수가 없습니다.**

---

### 6. 전장 서열 (full-length)

단백질 전체를 자르지 않고 통째로 넣은 것.

세포막 단백질은 세 부분으로 되어 있습니다:
```
[신호펩타이드] — [바깥쪽 도메인] — [막 통과] — [세포 안쪽 꼬리]
   흐물흐물        여기가 핵심        막대       흐물흐물
```

**우리는 전부 넣었습니다.** 논문도 그랬기 때문입니다.
(근거: 논문 그림에도 꼬리가 흐물흐물하게 그려져 있고, pTM 0.6이 그래야 나옴)

---

### 7. Ig 도메인 (면역글로불린 도메인)

단백질에서 **모양이 확실하게 잡힌 핵심 부분**. 우리 세 단백질 모두 여기에 변이가 있습니다.
발표에서는 "**변이가 있는 핵심 부위**"라고만 말해도 됩니다.

---

### 8. 노이즈 바닥 (우리가 만든 개념)

**같은 서열을 다시 예측해도 결과가 조금씩 다릅니다.** 그 차이가 "노이즈 바닥"입니다.

```
같은 서열 → 예측 → 구조 A
같은 서열 → 예측 → 구조 B     ← A와 B도 다름! 이게 노이즈
```

변이 때문에 생긴 차이가 **이 노이즈보다 커야** "변이 효과"라고 말할 수 있습니다.

**우리 결과**: CD33은 노이즈 0.124, 변이 차이 0.120 → **노이즈가 더 큼. 구분 불가.**

---

### 9. p값 (p-value)

**"이 정도 차이가 우연히 생길 확률"**입니다. 작을수록 우연이 아님.
보통 **0.05 미만이면 "우연 아니다"** 로 판정합니다.

**우리 숫자**

| | p | 뜻 |
|---|---|---|
| CD33 | 0.54 | 54% 확률로 우연 → **우연일 수 있음** |
| TREM2 | 0.0054 | 0.5% → 우연 아님 |
| PILRA | 0.000000006 | 거의 0% → 확실히 우연 아님 |

---

### 10. pQTL

**단백질 농도에 영향을 주는 유전자 위치**입니다.

이 논문의 핵심 아이디어: 같은 pQTL이 **두 가지 일을 동시에 합니다.**
```
① 단백질 농도를 바꾼다   → 통계(MR-SPI)가 쓰는 정보
② 아미노산을 바꾼다      → 구조 예측(AlphaFold)이 쓰는 정보
```
이게 논문 Slide 10의 "통계에서 구조로의 연결"입니다.

## PART 2 · 물어보면 답할 수준 (나머지 용어)

### 통계 파트 (Slide 3~9)

| 용어 | 쉬운 설명 |
|---|---|
| **교란 변수** | 원인처럼 보이지만 사실 제3의 범인. 예: 노화가 단백질도 바꾸고 병도 일으킴 |
| **도구변수** | 실험을 못 할 때, 원인만 흔들어주는 자연 장치. 여기서는 유전 변이 |
| **멘델 무작위화(MR)** | 유전자는 태어날 때 무작위로 정해지니, 이걸 "자연이 한 임상시험"으로 쓰는 방법 |
| **GWAS** | 수십만 명의 유전자를 훑어 병과 관련된 위치를 찾는 대규모 조사 |
| **SNP** | DNA 한 글자짜리 차이 |
| **다면발현(pleiotropy)** | 유전 변이가 우리가 보는 단백질 말고 **다른 길로도** 병에 영향을 주는 것. MR의 최대 골칫거리 |
| **최다득표 조건(plurality rule)** | "제일 큰 무리가 정답" — 과반(50%)까지는 필요 없다는 완화된 조건 |
| **최대 클리크** | 서로서로 다 동의하는 가장 큰 무리를 찾는 그래프 기법 |
| **Bonferroni 보정** | 912번 검사하면 우연히 걸리는 게 생기니, 기준을 그만큼 엄격하게 만드는 것 |
| **β̂ (베타햇)** | 인과 효과의 크기 추정값. +면 위험 증가, −면 감소 |
| **신뢰구간 포함률** | "95% 신뢰구간"이 진짜로 95% 맞히는지 검사한 값 |

### 구조 파트 (Slide 10~14)

| 용어 | 쉬운 설명 |
|---|---|
| **아미노산 / 잔기** | 단백질을 이루는 부품. 사람은 20종류. "잔기"는 단백질 안에 들어간 아미노산을 부르는 말 |
| **Arginine(R) / Glycine(G) / Histidine(H)** | 아미노산 이름. R은 팔이 길고, G는 팔이 거의 없음 |
| **Cα (씨알파)** | 아미노산마다 하나씩 있는 대표 탄소. 뼈대를 나타낼 때 씀 |
| **UniProt** | 단백질 서열 공식 데이터베이스 |
| **PDB / 결정구조** | 실제 실험으로 밝혀낸 구조를 모아둔 데이터베이스 |
| **신호펩타이드** | 단백질 맨 앞의 "주소표". 배달 끝나면 잘려나감 |
| **막관통(TM)** | 세포막을 뚫고 지나가는 부분 |
| **무질서 비율** | 구조가 안 잡히고 흐느적거리는 부분의 비율. 우리 값 0.41~0.61 |
| **시드(seed)** | 예측을 시작할 때 쓰는 난수 번호. 같은 시드면 같은 결과가 재현됨. **우리는 1로 고정** |
| **모델 5개** | AlphaFold Server가 작업 하나마다 자동으로 만들어 주는 후보 구조 5개 |
| **Mann–Whitney U** | 두 숫자 묶음이 정말 다른지 보는 검정법. 정규분포를 가정하지 않아 표본이 적어도 쓸 수 있음 |
| **정렬(align)** | 두 구조를 겹쳐 맞추는 것. 맞춰야 차이를 잴 수 있음 |

## PART 3 · 예상 질문 + 답

---

**Q1. pTM 0.6이면 낮은 거 아닌가요?**

> 네, 높지 않습니다. 다만 그건 단백질이 못 접혀서가 아니라 신호펩타이드와 세포질 꼬리가 흐물흐물해서 전체 점수가 깎인 것입니다. 실제로 변이가 있는 핵심 도메인만 보면 pLDDT가 94에서 97로 최상급입니다. 논문은 0.6을 "good prediction"이라 했는데, 결론은 맞지만 이유는 설명하지 않았습니다.

---

**Q2. 왜 7개 전부 안 하고 3개만 했나요?**

> 나머지 4개는 아미노산을 바꾸는 변이가 아예 없어서 변이형 서열 자체를 만들 수 없습니다. 논문도 3개만 그렸습니다. 초록에 "seven proteins with structural alterations"라고 쓰여 있어 오해하기 쉬운 부분입니다.

---

**Q3. 왜 전장 서열을 넣었나요? 꼬리는 잘라내는 게 낫지 않나요?**

> 논문 조건을 그대로 재현하는 것이 목적이었기 때문입니다. 논문에는 AlphaFold 방법 서술이 아예 없어서 어떤 구간을 썼는지 명시가 없습니다. 두 가지 근거로 전장이라고 판단했습니다. 첫째, 논문 그림에 흐물흐물한 꼬리가 그대로 그려져 있습니다. 둘째, 전장으로 넣어야 pTM 0.6이 재현됩니다. 도메인만 자르면 점수가 크게 올라갑니다.

---

**Q4. PILRA는 보통 G78R이라고 쓰지 않나요?**

> 문헌에서는 그렇게 씁니다. 그런데 UniProt 공식 서열의 78번은 이미 아르기닌이고, 이 변이는 R에서 G로 등재되어 있습니다. 논문 Figure S5도 "Arginine에서 Glycine으로"라고 적었습니다. 논문과 데이터베이스가 같은 방향을 쓰고 있어서 R78G로 표기했습니다.

---

**Q5. 노이즈 바닥 검정은 논문에 있는 건가요?**

> 없습니다. 저희가 추가한 부분입니다. 논문은 야생형과 변이형을 하나씩 겹쳐 보고 구조가 변했다고 결론지었는데, 그 차이가 모델 자체의 변동보다 큰지는 비교하지 않았습니다. AlphaFold Server가 작업마다 모델 5개를 자동으로 주기 때문에, 추가 예측 없이 기존 결과만으로 계산할 수 있었습니다.

---

**Q6. CD33이 구분 안 된다는 건 논문이 틀렸다는 뜻인가요?** ⭐ 제일 조심할 질문

> 아닙니다. 논문의 관찰 자체를 부정하는 게 아니라, 그 관찰에 기준을 하나 더한 것입니다. 논문은 구조가 변했다고 기술했고 실제로 그림상 차이는 있습니다. 다만 같은 서열을 다시 예측해도 비슷한 정도의 차이가 생기기 때문에, 그 차이만으로 변이 효과라고 단정하기는 어렵다는 것이 저희 결과입니다. 구조 예측으로 변이 효과를 논할 때는 모델 자체의 변동을 먼저 재야 한다는 게 결론입니다.

---

**Q7. MR-SPI는 왜 직접 안 돌렸나요?**

> UK Biobank 단백질체 요약통계가 필요한데, 이건 별도 신청 절차가 필요한 통제접근 자료입니다. 발표 일정 안에 확보가 어려워 통계 파트는 논문 결과를 인용하고, AlphaFold 파트만 직접 재현했습니다.

---

**Q8. TREM2는 통계적으로 유의한데 왜 의미가 작다고 하나요?**

> p값은 0.0054로 유의하지만 실제 차이는 0.26 Å 대 0.17 Å로 0.09 Å입니다. 원자 하나 크기가 1.5 Å인 걸 생각하면 매우 작은 값입니다. 그리고 UniProt은 이 변이에 대해 "단백질 구조에 영향을 주지 않는다"고 명시하면서, 실제 효과는 LDL이나 APOE 같은 리간드 결합 쪽에 있다고 기술합니다. 저희 수치가 그 주석과 방향이 맞습니다.

---

**Q9. 왜 갑자기 Boltz-2 얘기가 나오나요?**

> 라이선스 때문입니다. AlphaFold Server 약관은 비영리 사용만 허용합니다. 학교 과제인 이번 발표는 문제가 없지만, 서비스화를 생각하면 MIT 라이선스인 Boltz-2로 바꿔야 합니다. 향후 방향 슬라이드에서 그 점을 정리했습니다.

---

**Q10. 시드를 1로 고정한 이유는?**

> 재현 가능하게 하기 위해서입니다. 시드가 같으면 같은 결과가 다시 나오므로, 다른 사람이 검증할 수 있습니다. 논문은 시드를 밝히지 않았습니다.

## PART 4 · 모르는 질문이 나왔을 때

당황하지 말고 이 중 하나로 답하면 됩니다. **모른다고 말하는 게 틀리게 답하는 것보다 낫습니다.**

> "그 부분은 논문에 명시되어 있지 않아 저희도 확인하지 못했습니다."
> — 실제로 AlphaFold 방법 서술이 없는 논문이라 이 답이 사실인 경우가 많습니다.

> "그건 저희 재현 범위 밖이라 논문 값을 인용했습니다."
> — MR-SPI 통계 파트 질문 전부에 쓸 수 있습니다.

> "확인해보고 말씀드리겠습니다."
> — 가장 안전합니다.

## 부록 · 우리 숫자 한 장 요약

**재현 성공 근거**
```
CD33 pTM  우리 0.59~0.60  =  논문 0.6      ✅ 일치
```

**핵심 결과 (노이즈 바닥 검정)**
```
CD33   노이즈 0.124 Å  vs  변이 0.120 Å   p=0.54     → 구분 안 됨
TREM2  노이즈 0.168 Å  vs  변이 0.257 Å   p=0.0054   → 분리됨 (차이 0.09 Å)
PILRA  노이즈 0.100 Å  vs  변이 0.995 Å   p≈0        → 분리됨
```

**실행 조건**
```
도구   AlphaFold Server (AF3) — 논문과 동일
서열   UniProt 전장 (CD33 364 / PILRA 303 / TREM2 230 아미노산)
시드   1 고정
작업   6개 × 모델 5개 = 구조 30개
```

**대상 3개**
```
CD33   R69G   rs2455069
PILRA  R78G   rs1859788
TREM2  R62H   rs143332484
```
