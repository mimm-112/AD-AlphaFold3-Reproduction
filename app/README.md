# BlindSpot

**AlphaFold3 · Boltz-2 기반 미스센스 변이 구조 예측 감별력 검정 플랫폼**

동일 서열을 반복 예측해 모델 고유의 **재현 변동성**을 음성 대조군으로 확보하고,
야생형–변이형 간 구조 및 결합 인터페이스 편차가 이를 초과하는지 비모수 검정으로 판정하여,
해당 예측을 근거로 사용할 수 있는지 사전에 선별하는 시스템

**▶ https://mimm-112.github.io/AD-AlphaFold3-Reproduction/app/**

---

## 무엇을 하는가

구조 예측 모델은 야생형과 변이형에 대해 각각 구조를 산출하지만,
확률적 생성 모델의 특성상 **동일 서열에 대해서도 비결정적 출력**을 낸다.
따라서 관측된 구조 편차가 변이에 기인한 것인지 모델 재현 변동성인지 구분되지 않는다.

BlindSpot은 **동일 조건 반복 예측을 음성 대조군으로 삼아** 그 구분을 통계적으로 판정한다.

> **판정하는 것** — "이 예측을 구조적 변화의 근거로 사용할 수 있는가"
> **판정하지 않는 것** — 변이의 병원성·기능 변화·생물학적 의미

## 구현 현황

| 기능 | 상태 | 구현 |
|---|---|---|
| **UniProt 조회 · 잔기 대조 검증** | ✅ **실동작 · 임의 accession** | `app.js` `fetchUniProt` `validateMut` |
| 변이 서열 생성 · 도메인 자동 절단 | ✅ 실동작 | `buildSequences` |
| 입력 파일 배포 (FASTA · AF JSON · Boltz YAML) | ✅ 실동작 | `dlFasta` `dlAf` `dlBoltz` |
| 감별력 검정 재계산 | ✅ 실동작 | `mannWhitneyU` — 정규근사·연속성 보정·동순위 보정 |
| 분포 도표 | ✅ 실동작 | `drawStrip` — SVG 직접 생성 |
| 3D 구조 뷰어 | ✅ 실동작 | Mol\* · WebGL 미지원 시 사전 렌더 폴백 |
| **결과 ZIP 업로드 → 편차 계산·검정** | ✅ **실동작 · 임의 단백질** | `analyze.js` — mmCIF 파싱 · Horn 중첩 · 국소 RMSD |
| **구조 예측 실행** | ❌ 미구현 | GPU 필요. 사용자가 AlphaFold Server 에서 수행 후 결과를 업로드한다 |

### 워크플로우

```
① 앱      UniProt 조회 → 잔기 검증 → 서열 생성 → 입력 파일 배포
② 사용자   AlphaFold Server 에서 예측 (무료 · 하루 30건 · 작업당 모델 5개)
③ 앱      결과 ZIP 업로드 → mmCIF 파싱 → 중첩 → 국소 RMSD → 검정 → 판정
```

**GPU 가 필요한 ② 만 외부이며 나머지는 브라우저에서 완결된다.**
업로드된 파일은 서버로 전송되지 않는다 — 전부 클라이언트에서 처리한다.

### 편차 계산 (`analyze.js`)

| 단계 | 방법 |
|---|---|
| mmCIF 파싱 | `atom_site` 루프에서 Cα 추출, B-factor 를 pLDDT 로 사용 |
| 정렬 구간 | **양쪽 모두 pLDDT ≥ 70 인 잔기** — 무질서 구간이 정렬을 오염시키는 것을 방지하는 일반 규칙 (20잔기 미만이면 전체 사용) |
| 최적 중첩 | Horn 사원수법 (4×4 대칭행렬 Jacobi 고유분해) |
| 국소 RMSD | 변이 잔기 8 Å 이내 Cα · **재정렬 없이** 측정 |
| 기준 반복 | 같은 그룹 내 모델 쌍 |
| 변이 비교 | 그룹 간 모델 쌍 |

> ⚠️ 수록 사례(`src/rmsd_analysis.py`)는 알려진 도메인 경계로 정렬했고,
> 업로드 경로는 pLDDT 기준을 사용한다. 임의 단백질에는 도메인 주석이 없을 수 있기 때문이다.
> 절대값은 다를 수 있으나 판정은 일치한다 —
> CD33 R69G 검증: Python `기준 0.124 / 변이 0.120 · p 0.54`,
> 브라우저 `기준 0.194 / 변이 0.180 · p 0.82` — 양쪽 모두 **재현 변동성 내**.

### 용어 규약

UI 는 실무 용어를, 방법론 화면은 학술 용어를 사용한다.

| 개념 | UI 표기 | 방법론 표기 |
|---|---|---|
| 동일 서열 반복 예측 편차 | 기준 반복 변동 | 모델 재현 변동성 · 음성 대조군 |
| 야생형–변이형 편차 | 변이 비교 편차 | 처리군 편차 |
| 귀무가설 기각 | 재현 변동성 초과 | H₀ 기각 |
| 귀무가설 기각 실패 | 재현 변동성 내 | H₀ 기각 실패 |

**"재현 변동성 내"는 구조 불변이 아니라 모델 감별 한계를 의미한다.**
"미검출"·"실패" 등 오류를 연상시키는 표현은 사용하지 않는다.

## 서열 검증 — 이 앱의 첫 번째 실질 기능

`Q9UKJ1` + `G78R` 을 입력하면:

> **서열 불일치** — 입력하신 변이의 기준 잔기(Gly)가
> 야생형 서열 78번 잔기(**Arg**)와 다릅니다.
> 표기 방향이 반대일 수 있습니다. `R78G` 인지 확인해 주세요.

문헌은 PILRA 변이를 통상 `G78R` 로 표기하지만 UniProt 정본 78번은 이미 Arg 이며,
rs1859788 은 R→G 로 등재되어 있다. 논문 Figure S5(a) 주석도 `Arginine > Glycine` 이다.

본 재현 과정에서 실제로 이 오류를 사전 차단한 `src/sequences.py` 의 `assert` 규칙을 이식했다.

## 임의 accession 입력 시 동작

수록 사례가 아닌 단백질도 조회·검증·파일 생성까지 정상 동작한다.
**구조 검증 결과는 사전 산출된 4건에만 존재하며, 그 외 입력에는 다른 사례의 결과를 표시하지 않는다.**

예시 — `P36969` (GPX4_HUMAN, 197 aa):

| 단계 | 동작 |
|---|---|
| 조회 | `GPX4_HUMAN · 197 aa` · 도메인 주석 없음 |
| `R152H` 입력 | **차단** — 152번은 Lys (canonical 기준) |
| `U73C` 입력 | 통과 — 73번이 Sec(U)로 일치 |
| 도메인 절단 | 해당 위치를 포함하는 도메인 주석이 없어 전장으로 대체 |
| 비표준 잔기 | **경고** — Sec(U) 는 AlphaFold·Boltz-2 가 처리하지 못하므로 치환 필요 |
| 구조 검증 실행 | **사전 산출 결과 없음 안내** — 입력 파일을 내려받아 직접 예측하도록 유도 |

딥링크로 바로 재현 가능: `?s=s2&acc=P36969&mut=U73C`

## 통계 산출

`mannWhitneyU()` — 정규근사, 연속성 보정, 동순위(tie) 보정 포함.

| | |
|---|---|
| 구조 검증 | 단측 (처리군 > 음성 대조군), α = 0.05 |
| 인터페이스 검증 | 양측, α = 0.05 |

원자료 CSV 를 브라우저가 직접 읽어 계산하므로 **값이 하드코딩되어 있지 않다.**
SciPy 정확검정과 소수 셋째 자리에서 차이가 날 수 있으나 판정은 동일하다.
(예: CD33 구조 축 — 브라우저 `p = 0.53`, SciPy `p = 0.54`)

## 한계

- 예측 대 예측 비교이며 실험적 검증은 없다
- **재현 변동성 내 ≠ 구조 불변** — 모델 감별 한계를 의미한다
- ipTM 은 결합 자유에너지가 아닌 인터페이스 예측 신뢰도 지표다
- 산출되는 정렬은 **증거 사용 가능성 순위이며 생물학적 중요도 순위가 아니다**
